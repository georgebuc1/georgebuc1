## 🏖️ Featured project: vacanta-mea.ro

A live web application that aggregates travel offers for Romanian-speaking users. It includes a protected admin panel with offer creation and CSV bulk import, click tracking, price alerts and a contact form. It is SEO-ready and monetized through affiliate links.

### Tech stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend & database:** Supabase (PostgreSQL, Row Level Security, migrations, Edge Functions)
- **Email:** Resend, integrated through Supabase Edge Functions
- **Hosting & deployment:** Netlify, Cloudflare (currently testing Vercel)
- **Analytics:** Umami
- **SEO:** sitemap, robots.txt, Open Graph tags
- **Monetization:** affiliate programs (Booking.com via CJ Affiliate, Travelpayouts)
- **Scaffolding:** Bolt.new, then extended with custom infrastructure
